# Эксперимент подсчета покрытия и корреляции между предложенной атакой и настоящими пользователями

| Файл / папка | Содержимое |
|---|---|
| `images/` | 40 тестовых изображений `image_001.jpg` … `image_040.jpg` |
| `masks/` | 40 соответствующих PNG: фон 0, объект 255; размеры совпадают с изображениями |
| `clicks_1st_round.csv` | 600 кликов, координаты и размеры изображений |
| `metrics.csv` | 41 400 исходных значений IoU: 13 800 пользовательских и 27 600 результатов атак |
| `results.txt` | Две текстовые таблицы: coverage моделей и среднее; две корреляции Спирмена |
| `compute_metrics.py` | Автономный расчёт `results.txt`, только стандартная библиотека Python |

Запуск: `python compute_metrics.py`. Две таблицы выводятся в консоль и сохраняются в `results.txt` рядом со скриптом.

## Формат данных

В `metrics.csv` поле `source` определяет происхождение строки. Для `user` указан `click_id`, поле `strategy` пустое, `click_number=1`: это отдельные первые клики. Для `attack` указан метод `MIN`, `BASE` или `MAX` и номер последовательного шага 1–10; `click_id` пустой. Результаты связаны общими `model_id` и `image_id`. В `clicks_1st_round.csv` приведены пользовательские клики для всех изображений.

## Расчёт результатов

Для каждой пары «модель — изображение» границы после первого шага атак упорядочиваются: `L = min(MIN@1, MAX@1)`, `H = max(MIN@1, MAX@1)`. Coverage — доля из 15 пользовательских результатов, удовлетворяющих `L − 1e-9 ≤ user_iou ≤ H + 1e-9`.

Первая таблица в `results.txt` содержит 23 модели, отсортированные по убыванию точного coverage. При равенстве модели упорядочиваются по имени. В последней строке показано среднее по всем моделям — **58,51%**.

Вторая таблица содержит две корреляции Спирмена по 23 моделям. `AttackMIN_vs_UserMIN` сопоставляет среднюю нижнюю границу L со средним пользовательским минимумом; `AttackD_vs_UserD` сопоставляет среднюю ширину H−L со средним пользовательским диапазоном. Корреляции равны **0.9486166007905138** и **0.9239130434782609** соответственно.
